## 구조 결정

기존 `server/`, `user-auth/`는 비교용 코드로 그대로 둔다. 새 실행 경로는 루트 `package.json`, `api/`, `client/`이다. 두 기존 서버를 억지로 연결하는 대신 인증·자료·파일 경로를 하나로 통일한다. 데이터는 ignored `.data/`에 저장하며, 원본 저장소의 예제 JSON·계정·파일을 자동으로 운영 데이터로 가져오지 않는다.

핵심 흐름: 계정/독립 체험 → 팀 → PDF 업로드 → 논문 읽기 → 인용 카드/요약 → 검색·수정 → 내보내기.
