## 구현 · 실행 가능한 개인 개선 앱

- 루트 설치·빌드·실행 흐름을 만들고 인증, 자료, PDF 경로를 동일 출처 API로 통합했다.
- 평문 비밀번호를 scrypt 해시로 대체하고 세션 회전·로그아웃·팀 멤버십·소유자 권한을 검사한다.
- SQLite 저장과 파일 연결을 구성하고 재시작 유지·삭제 연쇄 처리·백업 복원을 검사했다.
- PDF 업로드·읽기, 논문 정보, 인용 카드, 요약, 검색·북마크, 팀원 관리와 내보내기를 완성했다.
- 외부 실패를 성공 요약으로 저장하는 방식과 가짜 임베딩을 제거했다. 기본 요약은 실제 원문 발췌임을 표시하고 외부 생성 요약은 선택 설정으로 구분한다.

## 검증 · 발견한 실패를 수정

- 독립 HTTP 검토에서 계정 간 접근, 잘못된 입력·파일, 세션 재사용, 공급자 실패·지연 중 권한 변경을 확인했다.
- 실제 브라우저에서 화면 대비와 PDF 표시 문제를 발견했다. 색상을 조정하고 자체 PDF 리더로 바꾼 뒤 검사했다.
- 모바일 레이아웃, 필터 초기화, 네트워크 실패 안내, 카드 페이지 이동, 팀 추가·제외·삭제를 확인했다.
- 새 폴더에서 `npm ci`와 빌드를 확인했다. 최종 결과는 HTTP·백업 22개 및 브라우저 7개 통과다.
- 원본 설명은 팀 결과물 문서로 보존하고, 루트 README를 새 앱의 사용법·기여 범위·한계 중심으로 작성했다.

## Windows 실행 안내 보완

- ZIP 사용자가 보관용 `server/`에서 실행하여 `build` 스크립트와 기존 라우터 파일 누락 오류를 만났다.
- 루트에서 실행해야 한다는 안내를 보완하고 자신의 위치로 자동 이동하는 `START_Windows.bat`를 추가했다.
- 실행 파일은 Node.js 24 및 새 앱의 package 이름을 확인하고 설치·빌드·시작 실패 시 중단한다.
- 새 앱의 기존 Linux 실행 검증은 유효하다. Windows CMD에서 실행 파일을 직접 구동하는 검사는 현재 환경에서 수행하지 못했다.
